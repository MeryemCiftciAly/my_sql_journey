# Cyberchase SQL Practice

## About the Exercise

This project is part of my SQL practice using the **Cyberchase** database from Harvard's **CS50's Introduction to Databases with SQL** course.

The exercise uses a database called `cyberchase.db` and a table called `episodes`, which contains information about episodes of the PBS educational television series *Cyberchase*.

The goal of the exercise is to use SQL queries to answer questions about the show's episodes.

## What I Practiced

The exercises provide practice with SQL concepts including:

* `SELECT`
* `WHERE`
* `ORDER BY`
* `LIMIT`
* Aggregate functions
* `GROUP BY`
* Filtering and sorting results
* Subqueries
* Working with dates and text
* Writing queries that return only the information needed to answer a question
